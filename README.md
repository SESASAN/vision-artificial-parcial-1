# Visión Artificial

Repositorio de los momentos evaluativos del curso Introducción a Visión
Artificial (docente Ricardo Franco Ceballos), organizado por parcial:

- [`parcial 1/`](parcial%201/README.md) — Momento Evaluativo 1: indexación de
  matrices y transformaciones de intensidad.
- [`parcial 2/`](parcial%202/README.md) — Momento Evaluativo 2: histogramas,
  filtrado espacial y detección/realce de bordes.

Ambos parciales comparten el mismo entorno virtual y `requirements.txt` en la
raíz del repositorio.

## Instalación

```bash
python3 -m venv .venv
```

Activar el entorno:

```bash
# Linux / macOS
source .venv/bin/activate
```

```bat
:: Windows (cmd)
.venv\Scripts\activate.bat
```

```powershell
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

Luego entra a la carpeta del parcial correspondiente y sigue su propio
README.
